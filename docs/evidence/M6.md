# M6 核心包与输出设备

Ubuntu 24.04.5 x86_64 用户态容器中，源码桌面自检完成 2 章导入、11 段生成及第一章导出，共 371937 帧。Qt FFmpeg 和 PulseAudio 虚拟设备 Novel_virtual_output 测得第 0 段播放位置 170 ms，暂停位置 170 ms；跳至第 2 段后，位置达 170 ms，播放速率 1.5。监视器录制共 62545 个单声道 PCM 样本，6187 个非零，振幅范围 -3696 至 3675。此为虚拟回环证据；实体声卡及原生桌面验收待测。截图见 reader.png。

Windows x64 便携预览使用已校验的 Windows CPython 和 uv.lock 中的原生 Windows wheels 装配，主入口 NovelTTSReader.exe，另附 NovelTTSReader.cmd。独立的 Windows 原生 Nuitka 构建在 package.yml 中定义。
