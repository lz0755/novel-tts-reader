Windows 11 x64，RTX 4060 Laptop GPU，显存 8,188 MiB，驱动 616.92。两档均以 Python 3.12.16、PyTorch 2.8.0+cu128、Qwen-TTS 0.1.1 运行，加载回报为 `bfloat16`、`sdpa_expanded_kv`、`inference_mode=true`。此环境没有另装 `flash_attn`。发布包用于验证桌面操作，推理使用本地已优化的独立运行时。 [环境、提交及文件摘要](windows-recheck-20261122.json)

**两档均已验证短章预生成和缓存回放，实时生成均未通过。** 每档从 5 个独立进程测启动至就绪，每次包含两次预热。最后一次预热后提交相同的 50 个未缓存请求，音色为 `vivian`，其中 40 次为 8–20 字短句、8 次为中句、2 次为长句，均走回环控制服务。短句使用 3 条固定文本重复生成。P95 取排序后的最近秩。 [逐次耗时、文本及显存曲线](windows-qwen-performance-20261122.json)

### 模型切换、异常与发行包

- 两档模型各核验 13 个固定版本的文件。用同一版本配置文件的回环副本验证 HTTP 206 续传，只传输了剩余 2,454 字节。篡改副本后校验拒绝加载。 [模型信息与文件摘要](windows-recheck-20261122.json)
- 桌面选择根目录 Python 时重现「本地运行时已退出」。改选 sidecar Python 及模型配置后，各有 9 种音色。0.6B → 1.7B → 0.6B 切换时，旧 worker 退出，当前仅一个推理进程。0.6B 省略风格参数，1.7B 对同一句保留中性和「低声而坚定」两份样音。 [切换、指令与音频指纹](windows-recheck-20261122.json)
- 两档的短、中、长句共 6 份，加上模型切换的 4 份样音，离线转写忽略标点后均与原文、句尾逐字一致。将独立测试配置的预算压至 48 token 后，真实推理拒绝 `missing_eos_or_token_cap`，产物接口返回 404、成功索引为零，下一任务重载后正常生成。 [预算、异常和转写对照](windows-recheck-20261122.json)
- Windows 发布包中三次切换均完成预生成，重开后可播放缓存，原生存盘对话框导出的 0.6B 章节为 2 段、230,400 帧。发布包控制服务在约 301 秒后回收无响应的测试 worker，菜单也能硬取消另一个正在等待的 worker。给单个测试进程设 1% CUDA 分配限额后，128 MiB 请求触发真实分配器 OOM。旧进程退出，书库新增 0 个 WAV。重新加载后，在 worker 的 Python 对外连接及域名解析受限、模型仅用本地文件的条件下，两段新文本预生成成功。 [发行包实机记录](windows-recheck-20261122.json)

### 听感与待测项

现场确认听见 Realtek 上的样书语音、测试音和 Qwen 朗读。同一句在 1、1.5、2 倍速时的人工反馈为「速度变快，音高基本保持」。两档各已生成全部 50 条纠音，按每 10 条一份 WAV 排列。0.6B 以两名角色、两种音色合成 30 句短对白，10 个连读组的样本、帧边界及角色切换均可核对。10 组短对白的离线转写有 8 组逐字一致。第 02、07 组的转写差异和逐句复识结果已记入 JSON，留给人工听审。第 7 组原文「我数三下」在连读转写中成了「火数三下」，第 2、7 组还有句末「了 / 啦」差异。 [样本清单及各段指纹](windows-recheck-20261122.json)

本机试听文件保存在项目的 `build/acceptance-recheck-20261122/试听样本/`，同目录有逐词和逐句清单。50 项纠音至少 45 项正确、短对白无漏复或串角、1.7B 风格对比仍待独立人工听评。按现场安排，每档从空缓存边生成边播 30 分钟和预生成后回放 30 分钟另约。Ubuntu 原生桌面、真实云端账号和账单也仍待补齐。 [52 项验收状态](../ACCEPTANCE.md)
